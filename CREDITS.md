# Credits and distribution

NPC Companions is an independent Dark Souls II: Scholar of the First Sin mod by **Lunaveli**, developed with AI assistance.

- Dark Souls II and its original NPCs, animations and game data belong to their respective creators and rights holders.
- **Dear ImGui** provides the in-game menu/overlay. Its license notice is included in the download.
- **MinHook** provides native function hooking. Its license notice is included in the download.
- **SilkySouls2** was used as a development/reference dependency; its notice is retained in the download.
- **SoulsFormatsNEXT**, **ESDLang/esdtool**, public parameter definitions and DS2 Mod Engine material were used during development to inspect/serialize data and understand the native interfaces.

This project is independent of Yui's Seamless Co-op and does not distribute its binaries or source.

The release contains the mod DLL/bootstrap, modified parameter/AI/dialogue/UI data and documentation. It requires an existing game installation; no game executable, original large game archives, models, textures, audio banks or player saves are supplied. Included third-party license notices remain in `NPCCompanions/licenses/` and retain their original terms.

This repository currently hosts release downloads and documentation. It does not grant an open-source license to all included game-derived material or imply endorsement by the game developers or other mod authors.
